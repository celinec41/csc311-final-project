# CSC311 Summer 2026 — Final Project

Predicting whether a student answers a diagnostic question correctly, using
the [Eedi](https://eedi.com/) dataset. This repository implements and
compares several collaborative-filtering / latent-variable models (Part A),
combines them into a bagged ensemble, and proposes and evaluates a novel
extension (Part B).

**Team:** Xiaohan Ma, Meixuan Lou, Siyi Chen

**Report:** [`report.pdf`](report.pdf) (generated from [`report.tex`](report.tex))

## Overview

Given a sparse student × question response matrix (1 = correct, 0 =
incorrect, missing otherwise), the goal is to predict unseen entries.

**Part A** implements and tunes four approaches:
1. **k-Nearest Neighbors** (user-based and item-based) — `knn.py`
2. **Item Response Theory** (1-parameter logistic model, gradient ascent) — `item_response.py`
3. **Neural Network Autoencoder** (matrix factorization via a shared-weight
   autoencoder, with L2 regularization) — `neural_network.py`
4. **Bagging Ensemble** of the three models above, via bootstrap resampling — `ensemble.py`

**Part B** proposes a hybrid extension to the KNN models: a validation-tuned
convex combination of user-based KNN, item-based KNN, and two low-variance
correctness priors (per-question and per-student average correctness) —
`Partb_KNN.py`.

## Results summary

| Model | Validation Acc. | Test Acc. |
|---|---|---|
| User-based KNN ($k=11$) | 0.6897 | 0.6847 |
| Item-based KNN ($k=21$) | 0.6916 | 0.6828 |
| IRT ($\eta=0.001$, 150 iters) | 0.7079 | 0.7030 |
| NN Autoencoder ($k=10$, lr$=0.03$, $\lambda=0.001$) | 0.6820 | 0.6760 |
| Bagging ensemble (kNN + IRT + NN) | 0.6868 | 0.6867 |
| **Part B: tuned hybrid (KNN + priors)** | **0.7115** | **0.7079** |

Full derivations, tuning curves, and discussion are in [`report.pdf`](report.pdf).

## Running the models

```bash
python knn.py                # Part A.1: KNN validation sweep + figure
python item_response.py      # Part A.2: IRT training + probability curves
python neural_network.py     # Part A.3: k/lr/epoch search, lambda search, final train
python ensemble.py           # Part A.4: bagging ensemble (kNN + IRT + NN)
python Partb_KNN.py          # Part B: tuned hybrid model + comparison figures
```

**Note on reproducibility:** `neural_network.py` and the NN component of
`ensemble.py` do not fix a PyTorch random seed, so re-running them will train
the autoencoder with different weight initializations and can produce
slightly different accuracy numbers on each run (the hyperparameters
selected — $k^*, \text{lr}^*, \lambda^*$ — are stable, but the exact final
accuracy will vary run-to-run by roughly $\pm1\%$). `knn.py`, `item_response.py`,
and the kNN/IRT components of `ensemble.py` are deterministic given the fixed
bootstrap seed (`seed=311`).
